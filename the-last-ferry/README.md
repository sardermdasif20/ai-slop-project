# THE LAST FERRY — শেষ নৌকা
A first-person 3D Bengali folk-horror game, designed for GitHub Pages.

## Story
In 1998, Rupa returns to a flooded river village where her brother Arif vanished eleven years earlier. The ferryman calls her by a family-only name. Recover six memories, discover why the river keeps voices, and decide whether to answer.

Inspired by Bengali river folklore and the urban legend of Nishir Daak. This is an original fictional story, not a retelling of a specific real event.

## Play
- Open `index.html` from a local web server, or publish this repository with GitHub Pages.
- Online play: GitHub → repository Settings → Pages → Deploy from branch → `main` / root.
- The game uses Three.js from jsDelivr CDN and Google Fonts, so an internet connection is required.
- Click Enter the Ghat, then use mouse to look.

## Controls
WASD / arrows: move · Mouse: look · Shift: run · E: interact · F: toggle lantern · Esc: release mouse
## Features
True real-time Three.js 3D scene, first-person controls, storm rain, volumetric-style ground mist, dynamic lantern, shadowed village houses, river and ferry, procedural environmental audio, sanity and oil systems, six memory collectibles, story conversations, and two endings.
