## 💻 RUN LOCALLY

1. Clone this repository:

```bash
git clone https://github.com/sardermdasif20/ai-slop-project.git
```

2. Open the project folder.
3. Enter the game folder you want to play.
4. Open its `index.html` in your browser.

Some games may require an internet connection for external libraries or resources.
