# NISHIR DAAK — The Voice After Midnight

A Bengali folk-horror exploration game inspired by the **Nishir Daak** (the night-caller) legend. The game is an original fictional interpretation: a voice calls people by name after midnight, mimicking someone they trust. The safest response is not to answer.

## Play
Open `index.html` in a modern desktop browser. No build step or installation is needed. Internet is only used for optional Google Fonts; all game logic, textures and audio are local.

- **WASD / Arrow keys:** walk
- **Shift:** run (uses breath)
- **E:** inspect / interact
- **F:** toggle lantern
- **M:** mute / unmute

## Experience
Explore a rain-soaked Bengali riverside neighbourhood, read found notes, inspect the old house and ghat, collect clues, manage fear and breath, and decide whether to trust the voice. Includes a large scrolling world, lighting and fog effects, animated rain, environmental audio beds, heartbeat tension, dialogue, clue progression, and multiple endings.

## Folklore note
Nishir Daak is a Bengali folk belief about a mysterious caller who imitates a familiar voice and lures a person outside at night. Details vary by region and retelling. This game is a respectful fictional adaptation, not a documentary account.
