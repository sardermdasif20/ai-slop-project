# ECHOES OF THE DEEP — Abyssal Salvage

A browser-based underwater exploration / survival game built with vanilla HTML, CSS and JavaScript.

## The idea
You are piloting a research submersible through the remains of the Asterion, a wreck lost at 240 metres. Recover five black-box data cores, then reach the extraction beacon. Your sonar reveals hidden salvage and the creature moving through the darkness — but each pulse attracts it.

## Play
Open `index.html` in any modern desktop browser. No installation, build step, server, or dependencies required.

### Controls
- **W A S D / Arrow keys** — steer the submersible
- **Space** — sonar pulse (reveals nearby data cores and the creature)
- **Shift** — short thruster boost
- **E** — collect a nearby data core / extract at the beacon

## Features
- Procedural-feeling underwater environment, wreck silhouette, drifting particles and seabed grid
- Sonar reveal mechanic with a risk/reward loop
- Leviathan AI that homes in more aggressively after sonar pulses
- Oxygen management, hull-contact damage, salvage objective and extraction win condition
- Responsive HUD, title screen, dive report and restart flow
- Original visuals rendered with Canvas; no external game engine

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `game.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Open the published Pages URL.
