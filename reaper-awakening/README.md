# REAPER: AWAKENING — Spirit Duel

A browser-playable, anime-inspired 2D action boss duel. Fight an original Hollow monarch with a soul-blade, ranged spirit waves, and a flash-step dash.

> Fan-inspired original prototype. It uses original character names and drawn canvas art; it is not an official BLEACH game and is not affiliated with the rights holders.

## Run instantly
Open `index.html` in Chrome, Firefox, Edge, or Safari. No installation, build tools, server, or API key required. Google Fonts are optional; the game still runs if fonts cannot load.

## Controls
- **A / D** — move left and right
- **W** — jump (avoid ground slams)
- **J** — close-range sword slash
- **K** — ranged spirit wave (uses spirit energy)
- **Shift** — flash step / dodge
- **P** — pause

## Features
- Original anime-inspired sword fighter and boss drawn with Canvas
- Boss attack patterns: charge, ground slam, and ranged spirit burst
- Telegraph effects, hit flashes, screen shake, particles, and aura
- Health and spirit-energy systems
- Responsive HUD and local best-run score
- No framework or external game engine

## GitHub Pages
1. Create a repository called `reaper-awakening`.
2. Upload `index.html`, `README.md`, and `LICENSE` to the root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`.
5. Save and open the Pages URL GitHub provides.
