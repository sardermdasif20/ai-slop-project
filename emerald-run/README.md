# EMERALD RUN — Beyond the Yellow Road

An original fantasy three-lane endless runner inspired by enchanted-road adventure stories and the visual mood of a magical land of emeralds. It is not an official Temple Run or Wizard of Oz game and uses no copyrighted characters or assets.

## Play
Open `index.html` in a modern browser. No install, build tools, server, or dependencies are required.

## Controls
- Left / Right arrows or A / D: change lanes
- Up arrow / W / Space: jump
- Down arrow / S: slide
- On touchscreens: swipe left, right, up, or down
- P / Esc: pause

## Features
- Three-lane endless-runner gameplay
- Jump, slide, lane switching and escalating speed
- Thorn arches, roots, broken road gaps and carts
- Collectible emeralds, distance tracking and local best score
- Original canvas-drawn fantasy environment and runner
- Custom parchment-and-emerald art-deco UI, title screen, pause screen and run report
- Responsive layout and swipe controls

## GitHub Pages
1. Create a new repository and upload `index.html`, `game.js`, and `README.md`.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the published Pages URL.
